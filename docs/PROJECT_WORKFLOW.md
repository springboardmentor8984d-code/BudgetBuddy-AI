# Project Workflow

1. User registers or logs in.
2. Backend validates credentials and returns JWT.
3. React sends JWT with protected API requests.
4. User records income and expenses.
5. User creates monthly/category budgets.
6. Expenses are compared with budget limits.
7. User creates savings goals and tracks progress.
8. Analytics APIs calculate financial summaries.
9. Dashboard visualizes spending and balance.
10. Expense data can be exported as CSV.
11. Backend can use PostgreSQL in production.

Milestone 1: Requirements, database design, backend setup and authentication.
Milestone 2: Expense, income and budget management.
Milestone 3: Savings goals, notifications, analytics and reports.
Milestone 4: Dashboard, charts, testing, validation and deployment.
