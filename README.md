# BudgetBuddy

BudgetBuddy is a full-stack personal finance management application designed to help users manage and monitor their finances in one place.

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- SQLAlchemy
- Alembic
- SQLite
- JWT Authentication

## ✨ Features

- User registration and login
- JWT-based authentication
- Protected API endpoints
- Income management
- Expense management
- Budget management
- Savings goals
- Financial dashboard
- User profile management
- Notifications
- Financial reports
